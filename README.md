# ShipOne

ShipOne es una extensión de VS Code para crear, organizar y seguir proyectos.

![ShipOne preview](media/branding/marketplace-preview.png)

## Branding

Los assets oficiales están en `media/branding/`.

## Desarrollo

```powershell
npm install
npm run compile
npm run watch
```

## Probar

1. Abrir el proyecto en VS Code.
2. Pulsar `F5`.
3. Ejecutar el comando `ShipOne: Mostrar bienvenida`.
4. Ejecutar el comando `ShipOne: Buscar proyecto`.

## Configuración

- `shipone.projectsRoot`
- `shipone.defaultVisibility`
- `shipone.openAfterCreate`
