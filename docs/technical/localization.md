# Localization

## Runtime text

ShipOne uses structured translation keys through `t()`.

## Files

- `package.nls.json`
- `package.nls.es.json`

## Scope

Localization should cover:

- commands;
- notifications;
- warnings;
- errors;
- placeholders;
- tooltips;
- onboarding;
- sidebar labels.

## Rule

Avoid hardcoded user-facing strings when a translation key exists.
