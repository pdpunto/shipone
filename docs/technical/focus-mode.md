# Focus Mode

Focus mode helps ShipOne show only what matters for the current project.

## What it shows

In focus mode, ShipOne keeps attention on:

- the active project
- the next action
- project health
- blockers
- the most relevant warning or quick action

## Why it exists

The goal is simple:

- reduce noise
- keep the next step visible
- make it easier to resume work

## When to use it

Use focus mode when you want to:

- stay on one project
- review a stuck project
- check the next action fast
- avoid scanning the whole list

## Relation with the tree view

The tree view still keeps the full project list.
Focus mode narrows the surface so the current project is easier to act on.

## Good output

A good focus mode view should:

- be short
- be readable
- show the next action first
- keep warnings actionable
