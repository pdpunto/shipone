# Good First Issues

These are small tasks for new contributors.

## Suggested tasks

- improve one doc page
- fix one translation string
- tighten one validation message
- add one small test
- improve one tooltip or label

## Good issue shape

A good first issue should be:

- small
- clear
- testable
- easy to review

## Before starting

- read the docs
- run the tests
- work on one task only
