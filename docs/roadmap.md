# ShipOne Roadmap

This page keeps the public direction of ShipOne short and clear.

## Now

- keep the extension stable
- keep the docs clean
- keep the release flow simple

## Next

- polish onboarding
- improve project recovery
- keep project health actionable
- keep focus and review flows easy to use

## Later

- add small quality-of-life improvements
- keep contributor setup simple
- improve release visibility when needed

## Rule

Only ship changes that are clearly useful.
