# Getting Started

## What ShipOne is

ShipOne is a VS Code extension for creating, organizing, and finishing projects with clear context.
The screenshots in the [main README](../../README.md) show a real view before you start.

## First launch

1. Open the repo in VS Code or install ShipOne from Marketplace.
2. Run the extension in development mode with `F5` when testing locally.
3. Open the `ShipOne` view in the sidebar.
4. Use `ShipOne: Create` to start a new project, or `ShipOne: Add existing project` if you already have one on disk.
5. If your projects are already inside `shipone.projectsRoot`, ShipOne will list them automatically.

## Recommended flow

1. Set your base folder in `shipone.projectsRoot`.
2. Create a project.
3. Add an existing project if you want to bring a real folder into ShipOne.
4. Review the `idea`, `active`, `paused`, or `finished` state.
5. Write a clear `nextAction`.
6. Use `Focus` to stay on one project.

## What to look at first

- `nextAction`
- project state
- project health
- recent changes

Open `troubleshooting.md` for the most common problems.
