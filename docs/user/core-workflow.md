# Core Workflow

## Real flow

1. Open ShipOne in the sidebar.
2. Create a new project, import an existing folder, or clone a GitHub repo into ShipOne.
3. If you already have projects in `shipone.projectsRoot`, ShipOne can list them automatically.
4. Choose type, folder, and Git/GitHub options for new projects.
5. Check that the project is `active` or in the right state.
6. Write a `nextAction`.
7. Work from the same view.
8. If you lose focus, use `Focus` or `Weekly review`.
9. If the project slows down, move it to `paused` or `finished`.
10. If the project no longer helps, delete it from the trash icon with confirmation.

## What matters most

- One active project at a time helps you focus.
- `nextAction` should be concrete.
- `STATUS.md` reinforces the context.
- Importing an existing project keeps the real folder intact.
- `Focus` cuts noise.
- `Weekly review` helps you resume work.
- `Delete project` clears what no longer adds value.

## Example

1. Create `my-saas-app`.
2. Choose `nextjs`.
3. Enable Git.
4. Write `nextAction: create login`.
5. Work until that part is done.
6. Mark the project as `finished` when it is ready.
