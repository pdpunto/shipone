# Contributing to ShipOne

Thanks for helping ShipOne.

## Setup rapido

1. Clona el repo.
2. Ejecuta `npm install`.
3. Ejecuta `npm.cmd run compile`.
4. Ejecuta `npm.cmd run test`.

## Before you open a PR

- Fork or branch from `main`.
- Keep changes small and focused.
- Run:
  - `npm.cmd run test`
  - `npm.cmd run lint`
  - `npm.cmd run compile`

## Good PRs

- One clear change per PR.
- Short description of what changed.
- Include steps to test it.
- Include screenshots if the UI changes.

## Project rules

- Write comments and messages in clear Spanish when possible.
- Do not commit secrets or `.env` files.
- Do not add dependencies without discussing it first.
- Do not mix unrelated changes in one PR.
- Prefer changes that are easy to review and easy to revert.

## Recommended flow

- Open an issue first if the change is large or unclear.
- Make one branch per task.
- Validate locally before asking for review.
- Keep the description short and concrete.

## Need help?

- Open an issue with a bug report or feature request template.
- Include expected behavior and reproduction steps.
- If something touches release or security, mention it clearly.
