# Contributing to ShipOne

Thanks for helping ShipOne.

## Before you open a PR

- Fork or branch from `main`.
- Keep changes small and focused.
- Run:
  - `npm.cmd run test`
  - `npm.cmd run lint`

## Good PRs

- One clear change per PR.
- Short description of what changed.
- Include steps to test it.

## Project rules

- Write comments and messages in clear Spanish when possible.
- Do not commit secrets or `.env` files.
- Do not add dependencies without discussing it first.

## Need help?

- Open an issue with a bug report or feature request template.
- Include expected behavior and reproduction steps.
