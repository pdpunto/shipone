# ShipOne

1. Open the ShipOne view in the sidebar.
2. Use **ShipOne: Create project** to create a new project.
3. Use **ShipOne: Add existing project** if you already have a folder on disk.
4. Use **ShipOne: Scan projects root** to import several folders from `shipone.projectsRoot`.
5. Choose Git and GitHub if you want to publish from the start.
6. Write a clear `nextAction` for the project.
7. Return to the ShipOne view to keep tracking progress.
